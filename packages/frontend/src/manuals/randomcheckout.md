# Random Checkout

Each leg gives everyone the same randomly chosen starting score. Reduce it to
exactly zero using **Straight**, **Double** or **Master out**. Master permits a
double or triple; inner bull counts as a double.

Choose **Checkout min/max** and **Visits per leg**. Overshooting, leaving 1
under Double/Master out, or finishing on an invalid ring busts the visit and
restores its starting score. Takeout releases a bust like any completed visit.

The first checkout wins the leg. Exhausting everyone's visit budget awards no
leg. **Continuous practice** automatically starts another target; **End game**
saves the session and compares actual checkout wins. With no checkouts there is
no winner. Disable continuous practice to use a finite legs/sets match instead.
Equal wins use seat order. A fresh target is shared by all players each leg.

Undo, correction, restart and resume retain the saved random sequence.
